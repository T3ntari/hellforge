## Changelog

### v1.0.0.0 ALPHA (2026-07-30)

Initial alpha release.

- Piano DSL compiler with LURE async engine
- REGAS/TENTARI signing system
- GPU compute via Radical and TensorSHARP
- OPENapi OpenGL and Vulkanizer backends
- EAudio with spatial audio and DSP effects
- Package management with embedded backups
- private registry verification (HF_VERIFY_URL, opt-in)
