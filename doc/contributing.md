## Contributing to HELLFORGE

### Code of Conduct

All contributors must adhere to the HELLFORGE Code of Conduct. Be respectful, inclusive, and constructive.

### How to Contribute

1. Fork the repository on GitHub
2. Create a feature branch
3. Write tests for your changes
4. Submit a pull request

### Development Setup

```
git clone https://github.com/hellforge/piano-dsl.git
cd piano-dsl
cargo build
cargo test
```

### Sign Your Commits

All commits must be signed with a TENTARI or REGAS key:

```
git commit -S -m "Add feature"
```

### Documentation

Documentation contributions are welcome. Follow the same signing and review process as code changes.
