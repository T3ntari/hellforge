# HELLFORGE v1.0.0.0 ALPHA — OpenAPI Commands

> Navigation: [doc/index.md](../index.md)

## openapi status
**Syntax:** `openapi status`
**Description:** Display the current status of the OpenAPI plugin, including API endpoint connectivity, rate limits, and available model deployments.
**Example:** `openapi status`
**Plugin:** openapi

## openapi extensions
**Syntax:** `openapi extensions list|install|remove <name>`
**Description:** List, install, or remove OpenAPI extensions that augment composition generation with AI model endpoints.
**Example:** `openapi extensions list`
**Plugin:** openapi

## openapi info
**Syntax:** `openapi info [--models] [--endpoints]`
**Description:** Display detailed information about configured API endpoints, available models, and authentication status.
**Example:** `openapi info --models`
**Plugin:** openapi
