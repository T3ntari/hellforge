Two Modes, One Engine

Every section compiles to the same unified event format: timestamp, MIDI note, duration, velocity, FX.

#HUMAN Fluid, property-chaining

Append @key:value properties for progressive depth. Missing values use smart defaults.

play note(C4)Single note (defaults: q, mf)
play note(D4) @dur:hWith duration override
play chord(C, major)Chord (expands to C4+E4+G4)
@vel:softNamed velocity (ppp–fff, 0–127)
@strum:down(20ms)Strum direction + gap
@dur:qDuration: w, h, q, e, s, or ms
// commentLine comments

#MACHINE AI-friendly token stream

Stateless, absolute-timestamp events. One line = one note. No state to track.

T1000 N60At 1000ms play middle C
D250Duration in ms
V0.8Velocity 0.0–1.0
P[bend:-12]Pitch bend in semitones
S[pan:-0.5]Stereo pan -1.0 to 1.0

Architecture

Text → Unification → Sound

1. Peggy parses each mode into a raw AST

2. Compiler converts both to unified {timestamp, midi, duration, velocity, fx}

3. Tone.js schedules all events sorted by timestamp

Modes can be mixed in a single file — just switch with #HUMAN / #MACHINE headers.
